# Segurança

Se encontrar uma vulnerabilidade no Portugal Agora, **não abra uma issue pública**. Use o [reporte privado de vulnerabilidades](https://github.com/bernardopaulino/portugal-agora/security/advisories/new) do GitHub, com os passos para a reproduzir.

Só a versão em produção ([portugalagora.pt](https://portugalagora.pt)) e o ramo `main` são mantidos.
